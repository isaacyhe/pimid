--------------------------------------------------------------------------------
QUICK REFERENCE - TOPOLOGY SELECTION
--------------------------------------------------------------------------------

For SMALL SYSTEMS (2-4 nodes):
  → Bus (simplest, lowest overhead)

For HIERARCHICAL WORKLOADS:
  → HTree (balanced tree structure)

For NEIGHBOR COMMUNICATION:
  → RingBus (excellent locality)
  → HTreeBus (bus shortcuts)

For GENERAL PURPOSE / HIGH PERFORMANCE:
  → HTreeBus (best overall performance)

For TESTING / BASELINE:
  → Bus (simple, predictable)

USAGE EXAMPLES
--------------------------------------------------------------------------------

# HTree topology with 8 CPUs
./build/X86/gem5.opt configs/example/garnet_synth_traffic.py \
    --topology=HTree --num-cpus=8 --network=garnet

# Bus topology with 4 CPUs
./build/X86/gem5.opt configs/example/garnet_synth_traffic.py \
    --topology=Bus --num-cpus=4 --network=garnet

# RingBus topology with 16 CPUs
./build/X86/gem5.opt configs/example/garnet_synth_traffic.py \
    --topology=RingBus --num-cpus=16 --network=garnet

# HTreeBus topology with custom latencies
./build/X86/gem5.opt configs/example/garnet_synth_traffic.py \
    --topology=HTreeBus --num-cpus=8 --network=garnet \
    --router-latency=2 --link-latency=1
