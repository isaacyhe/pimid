================================================================================
DETAILED INSIGHTS: MESSAGE PASSING vs SHARED MEMORY
================================================================================

1. SCENARIOS WHERE SHARED MEMORY OUTPERFORMS MESSAGE PASSING:
--------------------------------------------------------------------------------

   Memory Technologies (by execution time):
     • HBM: 32.2% faster
     • DDR5_VRR: 15.8% faster
     • HBM3: 12.4% faster
     • DDR3: 1.8% faster

   Workload Types (by execution time):
     • REDUCTION: 83.3% faster
     • SPMV: 8.3% faster
     • GEMM: 3.3% faster


2. ENERGY vs PERFORMANCE TRADE-OFFS:
--------------------------------------------------------------------------------

   Memory technologies where winners differ:

     HBM:
       Performance: Shared Memory (32.2% better)
       Energy:      Message Passing (2.3% better)

     DDR3:
       Performance: Shared Memory (1.8% better)
       Energy:      Message Passing (18.2% better)

     HBM3:
       Performance: Shared Memory (12.4% better)
       Energy:      Message Passing (4.6% better)


3. BEST AND WORST CASE SCENARIOS:
--------------------------------------------------------------------------------

   MESSAGE PASSING - Best Cases:
     • Performance: 1872.5% faster (Workload: bfs)
     • Energy:      381.1% better (Workload: bfs)

   MESSAGE PASSING - Worst Cases (loses to shared memory):
     • Performance: 83.3% slower (Workload: reduction)
     • Energy:      44.0% worse (Workload: reduction)


4. NETWORK ENERGY ANALYSIS:
--------------------------------------------------------------------------------

   Network Energy as % of Total Energy:
     • Message Passing: 33.3%
     • Shared Memory:   75.6%

   Shared memory has 42.3% MORE network overhead


5. ARCHITECTURE SELECTION RECOMMENDATIONS:
--------------------------------------------------------------------------------

   USE MESSAGE PASSING when:
     • Working with SRAM-based systems (145.9% energy advantage)
     • Running BFS workloads (1,872% performance advantage)
     • Running histogram operations (151.9% performance advantage)
     • Running prefix sum operations (255% performance advantage)
     • Energy efficiency is critical (consistently 55% better overall)
     • Working with DDR4/DDR5 memory (26-82% performance advantage)
     • Using GDDR6 memory (64.3% performance advantage)

   USE SHARED MEMORY when:
     • Running REDUCTION workloads (83.3% performance advantage)
     • Running SPMV workloads (8.3% performance advantage)
     • Running GEMM workloads (3.3% performance advantage)
     • Working with HBM (32.2% performance advantage)
     • Working with DDR5_VRR (15.8% performance advantage)
     • Working with HBM3 (12.4% performance advantage)
     • Working with DDR3 (1.8% performance advantage)

   CONSIDER TRADE-OFFS for:
     • HBM memory (shared memory is 32% faster but message passing uses 2% less energy)
     • HBM3 memory (shared memory is 12% faster but message passing uses 5% less energy)
     • GEMM workloads (shared memory is 3% faster but message passing uses 68% less energy)
